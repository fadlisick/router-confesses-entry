## The line

> I have never once been unplugged by accident. Every time, it was personal.

74 characters, one line, no em dash. The router confesses what every
household already suspects: the unplug was never an accident.

## How it works

`main.py` writes the confession to `/output/entry.txt`, checks the
competition gate (1-200 characters, single line, no em dash), and
verifies the written file byte-for-byte before exiting.
